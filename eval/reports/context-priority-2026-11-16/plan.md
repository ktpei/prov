# Fixed context-priority challenger

Compare the existing newest-first projection with one earlier-first challenger on
the same three exposed original-question FinanceBench histories. This is targeted
development after inspecting their retention failure, not an unseen test. Preserve
all earlier protocols, results, source bytes, packets and default agent behavior.

## Sole policy change

Retain the latest search and latest read exactly as before. Omit older searches.
Try optional non-search results oldest-first instead of newest-first, admitting
only complete results that fit the identical 32,000 serialized-output-string
character budget. Preserve call/output ordering, omission notices, errors and
explicit stops when required outputs cannot fit. No semantic ranking, answer
labels, numeric values, required roles, larger budget or extra read decisions.

Earlier reads correspond to better retrieval ranks only in this fixed ranked-parent
schedule. In arbitrary agent histories they may be stale or less relevant. The
synthetic discriminating test makes this tradeoff explicit: the policies keep
different optional reads under the same limit; neither generally dominates.

## Execution and attribution

Freeze this analysis, runtime, historical baseline analysis/protocol/result and
selection before execution. Exact-replay the baseline output bytes before running
the challenger. Use a freshly imported baseline analysis module and replace only
its local projector reference, checked against the expected production function;
restore it in finally, including interruptions. The shared production module is
never modified. The outer protocol binds the new policy; the derived challenger
result calls the old contract `input_integrity_protocol_sha256`, not its policy
protocol. The original baseline output remains byte-identical.

Both conditions use the historical reading runtime unchanged, verifying original
calls/journals and input identities. Each completes its projections before its
own packet access. Because baseline executes first in the same process, packet
labels have already been seen by that process before challenger execution. The
claim is strict projector data flow (messages and budget only), not process-wide
label secrecy. No labels feed selection or the priority rule.

Independent top-1/3/5 snapshots preserve all tasks, blocked projections, omitted
reads and failed slots. Record retained ranks, exact character use, complete and
per-role coverage, and paired wins/losses/ties. Preserve any regression. Each
condition performs 15 deterministic verification reads and six verification
searches; these are not extra agent decisions or paid inference.

The one-off implementation stays outside production runtime modules and has a
separate code hash. The historical runtime remains exact, avoiding compatibility
substitutions. Stop and retain the failed attempt if any frozen identity or replay
check fails; do not tune the rule after inspecting this run.

## Interpretation

This tests evidence retention under a fixed budget, not model reasoning, financial
accuracy, annotation adequacy or generalization. Keep the Ulta fiscal-year issue,
posthoc annotations and synthetic-history caveats. No automatic default promotion
follows even if all inspected cases improve. Broader fresh evaluation is needed.
